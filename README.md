# WATCHSTACK — 누구나 만드는 영화·드라마·애니 시청 리스트

회원가입 없이 바로 사용할 수 있는 오픈 정적 웹앱(PWA)입니다.

## 주요 기능

- 컬렉션 무제한 생성 · 이름/설명/아이콘/색상 변경 · 삭제
- 자유로운 그룹 구성 (페이즈, 시즌, 장르, 감독별 등)
- 영화, 드라마, 애니, 기타 작품 직접 추가 및 수정/삭제
- 볼 예정 / 보는 중 / 완료 3단계 관리, 드라마/애니 총 화수와 본 화수 기록
- 검색, 상태/유형 필터, 컬렉션별/그룹별 진행률
- 자동 저장 (`localStorage`), JSON 전체 백업/복원
- HTTPS에 배포 시 홈 화면 설치 및 오프라인 실행 지원
- MCU 필수 23편 예시: 나무위키 MCU 공식 페이즈 1~6 분류 기준으로 구분
- 예시에서 **가디언즈 오브 갤럭시**와 **어벤져스: 에이지 오브 울트론**은 시청 완료로 표시됨

## iPad에서 앱처럼 쓰기 (권장)

1. 이 폴더의 파일과 `assets` 폴더를 GitHub 저장소의 최상위에 업로드합니다.
2. GitHub 저장소 > Settings > Pages > **Deploy from a branch** > `main` / `/ (root)` > Save.
3. `https://사용자이름.github.io/저장소이름/` 형태의 HTTPS 주소를 Safari로 엽니다.
4. Safari **공유** 버튼 → **홈 화면에 추가** → **추가**를 누릅니다.
5. 홈 화면의 WATCHSTACK 아이콘을 눌러 앱처럼 실행합니다.

GitHub Pages는 퍼블릭 저장소에서 사용할 수 있습니다. 요금제와 정책에 따라 달라질 수 있습니다.

## 로컬에서 테스트

서버를 실행합니다 (Python 3 설치 필요):

```bash
python -m http.server 8000
```

그런 다음 `http://localhost:8000`을 엽니다. 로컬 파일 `index.html`도 기본 기능은 작동하지만 설치/오프라인 기능은 HTTPS 배포를 권장합니다.

## 데이터 및 개인정보

* 계정 가입, 중앙 서버, 실시간 동기화 기능은 없습니다.
* 생성한 모든 목록/시청 기록은 **해당 기기의 해당 브라우저 로컬 저장 공간**에 보관됩니다.
* Safari 브라우저 데이터를 지우면 기록이 사라질 수 있으므로 설정 > JSON 백업을 정기적으로 사용하세요.
* 다른 사람과 웹앱 주소를 공유하면 같은 앱을 각자의 별도 목록으로 사용할 수 있습니다. 서로의 기록은 공유하지 않습니다.
* iPad ↔ PC 기록 이전은 JSON 백업 파일 내보내기와 가져오기를 사용하세요.
