# WATCHSTACK — 영화·드라마·애니 체크리스트 (v1.2)

**기본 기능을 무료로 사용할 수 있는 정적 웹앱입니다.** 회원가입, 유료 API, 결제, 별도 서버, AI 연동이 없습니다. 공개 GitHub 저장소의 GitHub Pages를 통해 무료 배포하는 구조입니다. GitHub Pages는 서비스 정책과 사용량 제한의 적용을 받습니다.

## 주요 기능

- 영화, 드라마, 애니, 기타 컬렉션 자유롭게 생성·수정·삭제
- 페이즈, 시즌 또는 내가 정한 그룹으로 목록 구성
- 작품별 **봤음 / 안 봤음** 체크박스와 진행률
- 공개 연도, 제목, 메모, 작품 유형, 나무위키 문서 링크
- 작품 표지 이미지 URL 직접 지정 가능
- 표지를 지정하지 않은 경우 위키백과의 자유 라이선스 대표 이미지 탐색(무료 공개 API, 이미지가 없으면 글자 아이콘 표시)
- 작품 순서 및 그룹 순서 변경, 검색·필터
- 브라우저 자동 저장(localStorage) 및 무료 JSON 파일 백업/복원
- iPad Safari 홈 화면 추가, HTTPS에서 오프라인 실행(PWA)
- MCU 필수 23편 예시: MCU 페이즈 1~6, 가디언즈 오브 갤럭시 및 에이지 오브 울트론 시청 완료 표시

## 아이패드에서 실행하기

1. 공개 GitHub 저장소에 파일을 배치합니다.
2. GitHub 저장소 → **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
3. GitHub Pages 배포 후 `https://ozzosffo.github.io/watchstack/`에 접속합니다.
4. Safari **공유 버튼 → 홈 화면에 추가**로 앱처럼 사용할 수 있습니다.

## 비용에 관하여

- **OpenAI API, Cloudflare Worker, TMDB 유료 서비스, 서버 결제 등을 사용하지 않습니다.** `backend/worker.js`와 AI 연결/생성 기능은 v1.2에서 제거했습니다.
- 앱에서 결제하거나 유료 API 키를 입력할 필요가 없습니다.
- GitHub Pages는 공개 저장소에서 무료로 사용할 수 있으나 GitHub의 이용약관, 사용량 정책, 계정 설정을 따릅니다.
- 네트워크 이용요금(이동통신 데이터 등)은 사용자의 요금제에 따라 별도로 발생할 수 있습니다.
- 표지 이미지는 무료 위키백과 API 검색 결과에 따라 달라질 수 있으며 정확한 영화 포스터를 반드시 제공하지 않습니다. 저작권을 확인한 이미지의 HTTPS URL을 직접 넣을 수 있습니다.

## 데이터 보호

- 시청 기록은 서버에 보내거나 동기화하지 않고 **해당 브라우저 저장 공간**에만 저장합니다.
- 다른 기기 간 자동 동기화는 제공하지 않습니다. JSON 백업·복원을 사용하세요.
- Safari 데이터 삭제 시 시청 기록이 사라질 수 있습니다.
- 코드와 데이터 구조는 기존 v1.1과 호환되며 이전 체크 기록을 계속 유지합니다.

## 기술

HTML + CSS + JavaScript + Web App Manifest + Service Worker. 빌드 도구나 별도 패키지 설치가 필요 없습니다.
