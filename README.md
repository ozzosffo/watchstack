# WATCHSTACK · 나만의 시청 기록

영화·드라마·애니메이션을 컬렉션으로 모으고 **봤다 / 안 봤다** 체크박스로 관리하는 무료 PWA입니다.

**사용하기 → https://ozzosffo.github.io/watchstack/**

회원가입, 결제, 유료 API, 별도 서버, AI 연동이 없습니다. 기존 공개 저장소와 GitHub Pages 주소를 유지합니다.

## v1.5: 제목으로 찾아서 담기

- **작품 추가 → 제목 두 글자 이상 입력 → 후보 선택 → 작품 추가**
- 검색한 실제 영화·드라마·애니메이션의 제목, 공개 연도, 유형, 이미지와 나무위키 링크 자동 입력
- 새 컬렉션을 만들 때도 검색 결과에서 여러 작품을 골라 한 번에 담기
- 같은 컬렉션의 중복 작품과 새 컬렉션에 중복으로 담는 동작 방지
- 한글 조합 입력, 방향키·Enter 선택, Escape로 검색 결과 닫기 지원
- 후보를 먼저 표시하고 포스터·연도는 추가로 확인. 직접 수정한 정보는 덮어쓰지 않음
- 검색 결과가 없으면 ‘직접 입력 · 정보 수정’에서 기존 방식으로 추가 가능
- 기존 MCU 23편, ID·시청 체크·메모, 저장 키, 무료 GitHub Pages 주소 유지

## 가볍게 정리한 시청 노트

- 크림색 바탕, 세이지색 체크박스, 작은 웃는 로고와 폴더 모양 컬렉션
- 큰 배너·전체 통계·다음 작품 추천·사이드바·하단 메뉴·장식 문구 제거
- 컬렉션을 열면 작품 목록과 체크박스가 바로 보이는 구성
- 읽기 좋은 진한 글씨, 넓은 터치 영역, 아이패드·휴대폰 화면 대응
- 검색·시청 여부 필터는 바로 사용하고, 유형·그룹·포스터 보기는 ‘분류 · 보기’에서 설정
- 반복 상태 배지와 행마다 붙던 편집 메뉴 제거. 작품 제목이나 포스터 → 작품 편집
- 컬렉션·그룹·작품 추가·편집·이동, 포스터, 메모, 관련 문서 기능 유지
- MCU 23편과 기존 시청 기록, 자동 복구 사본·실행 취소·백업 보호 유지

## 데이터 보존

기존과 동일한 **watchstack_library_v1** 저장 키와 버전 1 자료 구조를 사용합니다. 유효한 기존 컬렉션·그룹·작품 ID와 시청 체크, 메모, 직접 지정한 이미지 주소를 유지합니다. 앱을 열기만 해서는 기존 시청 데이터를 다시 쓰지 않습니다.

첫 변경 전에 기존 원본을 **watchstack_library_v1_pre_v13**에 그대로 보관합니다. 삭제·백업 가져오기 전에는 **watchstack_library_v1_before_replace**에 직전 기록을 보관합니다. 설정 및 백업에서 복구 사본을 확인한 뒤 가져올 수 있습니다. 사본 저장도 실패하면 원본 덮어쓰기를 진행하지 않습니다.

잘못된 JSON, 지원하지 않는 버전, 읽을 수 없는 목록을 발견하면 샘플로 덮어쓰지 않고 편집을 중단합니다. 설정에서 원본을 내려받고 정상 백업으로 복구할 수 있습니다. 동시에 연 다른 탭의 기록도 확인하며, 오래된 편집 창의 저장을 막습니다.

기록은 **각 기기의 각 브라우저**에 저장합니다. 계정이나 기기 간 자동 동기화는 없습니다. 홈 화면 앱과 브라우저의 저장 공간이 다를 수도 있으므로 설치하거나 다른 기기로 옮기기 전 JSON 백업을 권장합니다. 브라우저 데이터를 삭제하면 복구 사본도 함께 삭제될 수 있습니다.

## 아이패드·아이폰에서 사용

1. Safari에서 위 사이트를 엽니다.
2. **공유 → 홈 화면에 추가 → 추가**를 누릅니다.
3. 앱을 한 번 온라인으로 연 뒤에는 오프라인에서도 저장한 목록을 확인하고 체크할 수 있습니다.
4. 다른 기기에서는 **설정 및 백업 → 백업 가져오기**로 옮깁니다.

새로 불러오는 외부 이미지와 외부 문서는 인터넷 연결이 필요합니다. 새 버전이 준비되면 안내에서 업데이트할 수 있습니다. 입력 중인 폼이 있으면 먼저 저장하거나 닫아야 업데이트합니다.

## 포스터와 작품 정보

MCU 23편의 표시용 이미지 주소와 출처를 catalog.js에 분리했습니다. 사용자가 직접 입력한 포스터 주소가 우선이며, 기존 저장 데이터에 포스터 정보를 강제로 쓰지 않습니다. 일부 드라마의 이미지는 포스터 대신 작품 로고입니다.

새 작품 검색은 [위키백과 공개 API](https://www.mediawiki.org/wiki/API:Search), Wikidata와 영어 위키백과의 작품 정보를 조합합니다. 애니메이션이 원작 소설·만화 문서에 합쳐져 있는 경우 [TVmaze의 무료 공개 API](https://www.tvmaze.com/api)에서 실제 TV 작품을 추가로 찾습니다. API 키나 회원가입이 필요하지 않습니다. TVmaze 정보에는 작품 출처 링크를 표시하고 데이터의 CC BY-SA 출처 정보도 함께 저장합니다.

두 글자 이상 입력한 뒤 420ms 기다려 검색하며, 이전 요청 취소와 5분 메모리 캐시를 사용합니다. ‘가오갤’, ‘귀칼’, ‘리제로’ 등의 약칭도 일부 지원합니다. 고르기만 해서는 시청 기록에 쓰지 않으며, ‘작품 추가’ 또는 ‘컬렉션 만들기’를 눌렀을 때 선택한 정보를 저장합니다. 저장한 작품 정보는 인터넷 없이도 확인할 수 있습니다.

대표 이미지가 포스터 대신 로고·표지일 수 있고, 공개 데이터에 없는 작품이나 이미지도 있습니다. 이미지가 없거나 연결에 실패하면 제목과 아이콘을 표시합니다. ‘직접 입력 · 정보 수정’에서 유형·연도·이미지 주소를 수정할 수 있습니다. 예전 직접 입력 작품의 빈 이미지는 기존의 자유 라이선스 대표 이미지 검색으로 보완합니다.

나무위키는 문서 제목이 작품명과 다를 수 있어 새 검색 작품에는 **해당 제목의 나무위키 검색 링크**를 붙입니다. 정확한 문서 제목을 직접 지정하면 해당 문서로 연결합니다. 기존에 지정된 나무위키 문서 링크는 유지합니다.

이미지 출처는 작품 정보에서 연결합니다. 이미지의 권리는 각 권리자에게 있으며, 외부 이미지를 재배포하지 않습니다. 나무위키 외부 문서에는 스포일러가 있을 수 있습니다. 작품 정보에 유료 API 키나 결제 수단은 필요하지 않습니다.

## 무료 배포

별도 설치·빌드 없이 저장소 루트의 HTML/CSS/JavaScript를 GitHub Pages로 제공합니다.

- 공개 저장소: https://github.com/ozzosffo/watchstack
- Pages 설정: **main / (root)**
- 유료 서버·유료 API·결제·광고 SDK·분석 SDK·AI 백엔드를 추가하지 않았습니다.
- .nojekyll을 포함해 정적 파일로 배포합니다. package.json의 의존성은 개발 테스트 전용으로 앱에서 로드하지 않습니다.
- GitHub Pages의 서비스 정책과 사용량 제한, 사용자의 통신 요금은 해당 서비스 조건을 따릅니다. 앱 자체에 사용량에 따른 유료 전환 기능은 없습니다.

## 개발·테스트

Node.js 20 이상에서:

    npm ci
    npm test

실제 사용자 기록을 포함하지 않는 이전 v1.2 샘플 픽스처로 데이터 보존과 기본 작업 흐름을 검증합니다. 공개 API 응답에서 필요한 필드만 남긴 검색 픽스처로 영화·드라마·애니 분류, 포스터·연도·출처 처리도 검사합니다. 서비스 워커는 설치·업데이트·오프라인·캐시 범위를 별도로 검사합니다.

검증 내용과 실기기 확인 범위: [docs/verification.md](docs/verification.md)

HTML + CSS + JavaScript + Web App Manifest + Service Worker. WATCHSTACK은 마블·디즈니·위키미디어와 제휴 관계가 아닙니다.
