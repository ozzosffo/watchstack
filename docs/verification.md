# WATCHSTACK v1.5 검증 기록

## v1.5 작품 검색

6d92971b9277499f6aeaf58df8a5fdd2967b97e5의 v1.4를 기준으로 작품 자동완성과 선택 추가를 구현했습니다. 새 컬렉션에서는 여러 편을 담고, 기존 컬렉션에서는 그룹을 정해 한 편씩 추가합니다. 수동 입력과 기존 기록 편집도 유지합니다. 공개 API 검색 결과를 선택한 항목에만 출처·식별자 필드를 추가하며, 기존 저장 자료를 일괄 변환하거나 다시 쓰지 않습니다.

- 한국어 위키백과의 접두·본문 검색, Wikidata의 최초 공개/방영 연도, 영어 위키백과의 대표 이미지 사용
- 원작 소설·만화 문서로만 검색되는 작품은 TVmaze의 실제 TV 작품으로 보완하고 출처 링크 표시
- ‘인터스’ → 인터스텔라, ‘귀멸’ → TV 애니 및 극장판, ‘가오갤’ → 영화 시리즈, ‘리제로’ → TV 애니를 실제 HTTPS 응답으로 확인
- 제목·연도·유형을 먼저 표시한 후 이미지 보완. 선택 뒤 도착한 정보는 직접 수정하지 않은 필드만 보완
- 검색 취소, 중복 방지, 한글 조합, 키보드, 폼 종료·늦은 응답·저장 실패 검사
- 나무위키의 정확한 문서 존재 여부를 추정하지 않고 제목 검색으로 연결. 직접 지정한 문서는 직접 연결
- 유료 API·키·서버·빌드·새 배포 서비스를 추가하지 않음

## 기준 버전과 변경 전 확인

- 배포 주소: https://ozzosffo.github.io/watchstack/
- 배포된 app.js를 내려받아 저장소 파일과 바이트 단위로 일치함을 확인했습니다.
- DOM 실행으로 MCU 23편, 6개 페이즈, 기본 완료 2편, 체크 저장과 재실행 시 ID·기록 보존을 확인했습니다.
- 손상된 저장 데이터가 샘플로 대체되고 이후 변경 시 덮어써지는 기존 문제를 재현했습니다.
- 기존 버전은 저장 실패를 사용자에게 알린 뒤에도 성공 안내를 계속할 수 있고, 백업 가져오기가 전체 교체만 지원했습니다.

## v1.4 화면 정리

13853b4 기준의 v1.3에서 배너, 전체 통계, 다음 작품 카드, 사이드바, 하단 메뉴, 반복 편집 버튼과 상태 배지를 제거했습니다. 크림색·세이지색의 가벼운 목록으로 바꾸고 분류·보기 설정은 접었습니다. 작품 편집은 제목·포스터를 눌러 정보 화면에서 접근합니다.

저장 키와 자료 구조, 데이터 읽기·쓰기·백업 로직은 변경하지 않았습니다. 기존 회귀 테스트의 편집 경로를 실제 새 화면의 경로에 맞춰 검사했습니다.

## 구현한 보호 장치

- 기존 주소, 저장 키, 버전 1 자료 구조, MCU 항목과 순서를 유지합니다.
- 기존 사용자 기록을 읽기만 했을 때는 기본 시청 데이터를 쓰지 않습니다.
- 첫 변경 전 원본 사본과 삭제·가져오기 전 사본을 별도 키에 보관합니다.
- 저장·사본 작성 실패 시 UI와 메모리를 원래 상태로 되돌립니다.
- 잘못된 JSON이나 향후 버전은 읽기 보호 상태로 열어 원본이 사라지지 않게 합니다.
- 백업은 미리보기 후 기본적으로 추가하며, 교체는 별도로 선택합니다.
- 여러 탭의 변경을 반영하고, 오래된 폼과 저장 직전의 충돌을 검사합니다.

## 검증의 범위

이 환경에서 사용 가능한 DOM 실행과 서비스 워커 모의 환경으로 기능을 검사했습니다. 실제 Safari/Chrome 브라우저의 화면 렌더링, 터치 동작, 홈 화면 설치와 비행기 모드 실행은 기기에서 확인하지 않았습니다.

사용자 개인 아이패드의 브라우저 저장 공간에는 접근하지 않았습니다. 데이터 보존은 이전 버전 샘플·사용자 정의 기록을 담은 픽스처와 오류 사례로 검사한 결과입니다.

외부 Wikimedia·TVmaze 이미지 주소를 사용하며, 일부 작품은 로고·표지를 표시합니다. 모든 작품의 검색·공식 포스터를 보장하지 않습니다. 외부 이미지와 문서는 네트워크 상태나 원본 변경에 영향을 받으며 오프라인 캐시 대상이 아닙니다.
