## 구현한 보호 장치

- 기존 주소, 저장 키, 버전 1 자료 구조, MCU 항목과 순서를 유지합니다.
- 기존 사용자 기록을 읽기만 했을 때는 기본 시청 데이터를 쓰지 않습니다.
- 첫 변경 전 원본 사본과 삭제·가져오기 전 사본을 별도 키에 보관합니다.
- 저장·사본 작성 실패 시 UI와 메모리를 원래 상태로 되돌립니다.
- 잘못된 JSON이나 향후 버전은 읽기 보호 상태로 열어 원본이 사라지지 않게 합니다.
- 백업은 미리보기 후 기본적으로 추가하며, 교체는 별도로 선택합니다.
- 여러 탭의 변경을 반영하고, 오래된 폼과 저장 직전의 충돌을 검사합니다.

## 검증의 범위

이 환경에서 사용 가능한 DOM 실행과 서비스 워커 모의 환경으로 기능을 검사했습니다. 실제 Safari/Chrome 브라우저의 화면 렌더링, 터치 동작, 홈 화면 설치와 비행기 모드 실행은 기기에서 확인하지 않았습니다.

사용자 개인 아이패드의 브라우저 저장 공간에는 접근하지 않았습니다. 데이터 보존은 이전 버전 샘플·사용자 정의 기록을 담은 픽스처와 오류 사례로 검사한 결과입니다.

외부 Wikimedia 이미지 주소를 사용하며, 일부 TV 작품은 로고를 표시합니다. 외부 이미지와 문서는 네트워크 상태나 원본 변경에 영향을 받으며 오프라인 캐시 대상이 아닙니다.
